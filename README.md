# NotchRail 🏝️

> **把被 MacBook 刘海挤走的菜单栏，优雅延伸到灵动岛。**
> 
> *An extended, non-invasive menu bar mirror for MacBook notch & external displays.*

## 📖 背景痛点

配备硬件刘海的 MacBook 极大压缩了顶部状态菜单栏的横向显示空间。当打开较多状态栏常驻工具（开发客户端、云同步、通信工具、系统监控等）时，超出刘海右缘的图标会被 macOS 强制推入屏幕外或直接被刘海物理遮挡，导致用户**看不见、点不到、无法接收状态变化通知**。

**NotchRail** 采用纯粹的**非侵入式镜像架构**：不注入私有布局、不插入占位符 Spacer、不干扰原生菜单栏，直接在刘海正下方提供一个优雅伸缩的扩展灵动岛，将所有被遮挡的图标无感重现与交互。

## ✨ 核心特性

- 🚀 **毫秒级极速扫描**：通过 macOS SkyLight 窗口系统、单次批量窗口描述提取与非阻塞异步辅助功能架构，精准扫描状态栏窗口层级（`kCGStatusWindowLevel`），零 UI 卡顿。
- 🔋 **能耗与发热根治 (Smart Heartbeat)**：菜单栏扫描按三档节拍运行 —— `Dormant`（完全休眠，定时器彻底挂起，空闲零 CPU）、`Armed`（光标靠近顶边热区时单次增量预热，展开第 0 帧位图即命中）、`Active`（展开态按固定心跳周期刷新，收起后经冷却期回归休眠）；窗口指纹未变的静态图标**不再重复创建 `CGContext` 与像素扫描**；全局鼠标移动事件按固定间隔节流（防抖高刷鼠标），并在屏幕中下部无关区域 0 开销熔断。
- 🪄 **内容驱动动态自适应耳翼 (Dynamic Wings)**：
  - **0 溢出基准态**：紧凑态宽度严格 1:1 贴合硬件刘海物理尺寸，两端零多余外展；
  - **有溢出态**：左侧动态平滑长出耳翼（Left Wing），黄色计数徽标完整呈现于可用发光屏幕区，彻底告别物理黑胶遮挡；
  - **右侧平齐**：右侧与刘海右缘保持 0 延展平齐，绝不遮挡原生 Wi-Fi、电池等状态栏图标。
- 🎨 **像素级高保真镜像与第 0 帧秒开**：直接采集系统真实菜单栏位图，**零降级、无任何占位符**。后台与快照原子化同步预热，展开灵动岛瞬间**第 0 帧直接呈现高清真实图标**，去除多余常态线框与内边距挤压，还原原生通透观感。
- 🗂️ **全局应用图元注册表 (Application Asset Vault)**：以 `bundleIdentifier` 为索引登记任一激活屏幕捕获到的真实位图；当 WindowServer 对非聚焦屏幕暂停菜单项光栅化（截图返回全透明）时，非激活屏展开灵动岛直接按确凿 Bundle ID 直出真实位图 —— 0 跨屏借调、0 兜底、0 错配。
- ⚡ **原生事件精准穿透路由**：点击灵动岛内的图标时，通过合成底层 `CGEvent` 精确分发至目标窗口与进程（`postToPid`），原生唤起原应用的下拉菜单。
- 🛡️ **双重硬件级事件穿透 (彻底根除透明遮挡)**：采用稳固吸顶视口 + 全局 `MouseMonitor` 动态事件穿透（`ignoresMouseEvents`），紧凑态仅在刘海与耳翼有效区域认领鼠标，下方及两侧透明区域 100% 物理直通底层应用（Chrome 标签栏、书签栏、网页操作毫秒级直通）。
- 🕹️ **多模式触发与物理弹性动效**：
  - **多通道触发方式**：支持「鼠标悬停（默认）」、「仅点击展开」、「悬停或点击」三种交互通道；
  - **防误触时序**：移入意图识别（快速划过不误触）+ 移出离开缓冲（Grace Period），两者时长均可在设置中调节；
  - 遵循 Apple 物理弹簧阻尼动画曲线，宛如原生系统组件。
- 🌌 **全屏沉浸协同与顶边缘碰顶唤醒**：在全屏应用（Xcode、全屏视频、幻灯片、游戏等）下自动隐退视口（完全透明且 100% 物理穿透，零遮挡）；当光标碰触屏幕顶边缘窄带热区时随系统菜单栏平滑淡入，移出后平滑隐退，兼顾极简沉浸与随时唤出。
- 🖥️ **多屏独立多实例架构与零溢出隐藏**：
  - **每屏一套视口与状态机**：MacBook 物理刘海屏的视口**永久守护**，紧凑胶囊与黄色溢出徽标始终常驻；其余每块显示器各自拥有独立视口，折叠常态完全隐形且鼠标物理直通，触碰顶部中央受限热区并停留片刻后原位展开统一的纯黑仿真灵动岛；
  - **屏幕数量不设上限**：内置刘海、单平直屏（Mac mini / 盒盖模式）、双外接乃至更多屏幕的任意组合均自适应，主屏视口常驻、其余屏按需装载；
  - **零跨屏抢夺**：各屏各持独立状态机与穿透流，聚焦在显示器间移动时 0 撕裂、0 徽标闪烁、0 视觉瞬移，彻底告别「余光小胶囊消失」；
  - **全拓扑自适应**：智能适配 MacBook 刘海屏与平直屏的任意组合；多屏策略支持聚焦跟随（`followFocusedScreen`）、仅主屏（`mainScreenOnly`）或外接屏禁用；
  - **零溢出自动隐藏**：原生菜单栏无遮挡时自动隐藏胶囊。
- 🖱️ **岛内流体拖拽重排与原生点击透传**：展开态下可直接拖拽图标进行流体位移重排，松手后原子持久化自定义顺序（`customItemOrder`），未排序项按物理坐标依序追加；**左键单击**与**辅助点击（触控板双指点击 / 鼠标右键）**均按窗口 ID 原样透传给对应状态项，由第三方应用自己弹出原生下拉菜单与上下文菜单，绝不改用自绘菜单顶替；若该状态项确实没有对应的辅助点击处理，图标以抖动反馈告知，不静默。
- 📱 **极简应用管理面板与现代化 UI**：全面重构应用管理卡片质感，自适应长方形/正方形图标容器，双档清晰状态徽标（`岛内展示 (溢出)` / `原生可见`），并支持一键重置恢复默认排序。
- 🛠️ **全新现代化设置中心 (Settings)**：
  - **常规**：触发方式、点击自动收起、触觉震动反馈、无溢出自动隐藏、多屏策略、托盘图标、开机自启与退出控制；
  - **悬停与动效**：防抖与宽限时延精细滑块调节；
  - **应用管理**：全局活动应用快照同步对齐、模糊搜索、状态栏实时镜像状态与一键重扫；
  - **关于与诊断**：辅助功能与屏幕录制权限实时检测、一键重扫与状态刷新。
- 📥 **系统菜单栏常驻托盘 (`tray.full.fill`)**：提供一键开关灵动岛、重新扫描、偏好设置 (⌘,) 和退出 (⌘Q)。
- 🔒 **100% 纯本地运行与隐私保护**：无任何网络通信、无第三方遥测追踪，代码完全开源。

## 📥 下载与安装

### 方式一：直接下载安装包（推荐）

1. 前往 [GitHub Releases](https://github.com/AeroSheepZ/NotchRail/releases/latest) 下载最新发布的 `.dmg` 或 `.zip` 分发包。
2. 打开下载的 `.dmg` 镜像，将 **NotchRail** 拖入 **Applications (应用程序)** 文件夹。
3. 在「应用程序」中启动 NotchRail。

> **提示**：首次打开如遇 macOS Gatekeeper 提示未签名开发者：
> 请前往「系统设置」→「隐私与安全性」→ 滑动至底部点击「仍要打开」。

### 方式二：从源码编译构建

```bash
# 1. 克隆仓库
git clone https://github.com/AeroSheepZ/NotchRail.git
cd NotchRail

# 2. 编译并打包 App / DMG / ZIP
bash scripts/build_app.sh

# 3. 运行 App
open build/NotchRail.app
```

## 🔐 权限说明

为了提供完整的状态栏捕获与点击交互体验，NotchRail 需要以下两项系统权限：

| 权限项 | 对应系统 API | 用途说明 |
| :--- | :--- | :--- |
| **辅助功能 (Accessibility)** | `AXIsProcessTrusted` / `CGEvent` | 用于将用户在灵动岛上的点击事件精准派发给对应目标应用 |
| **屏幕录制 (Screen Recording)** | `CGWindowListCreateImageFromArray` | 用于捕获被刘海物理遮挡的菜单栏图标实时像素（仅本地内存捕获） |

*首次启动时，应用会弹出权限指引面板协助您一键开启。可在「设置」→「关于与诊断」中随时查看与刷新授权状态。*

## 🧩 架构设计

NotchRail 采用双 Target 模块化设计：**`NotchRailKit`**（核心框架库）+ **`NotchRail`**（宿主 App 可执行文件入口）。
