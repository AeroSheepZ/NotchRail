# 0004. 零降级真实窗口位图镜像与增量像素比对

### 背景
菜单栏项本质是单色图标或动态文字（如实时网速、电量、CPU 使用率、时钟）。传统扩展工具在捕获失败或加载阶段往往降级显示 App 的彩色 Dock 大图标或 SF Symbol 通用占位符。这破坏了菜单栏原生的暗黑单色极简语境，且 Dock 图标无法承载任何动态实时信息；若用户未授予屏幕录制权限，更会导致灵动岛沦为杂乱的 Dock 栏。

### 决议
1. 坚守 **100% 真实 WindowServer 位图镜像**：通过 `CGWindowListCreateImageFromArray` 按 windowID 单独截图，并执行透明边缘动态裁切，保留原生比例与观感。
2. **零彩色降级**：加载中或捕获未完成阶段，统一采用中性呼吸脉动胶囊（PulsingCapsule），捕获完成后原位无感替换；坚决不引入彩色 Dock 图标或 SF Symbol 替代品。
3. **视觉相等性比对（Visual Equality）**：通过 `isVisuallyEqual` 对比内存帧缓冲，像素未变化时 0 渲染开销，动态数值实时增量刷新。
4. **失败熔断**：单窗口连续 3 次捕获失败进入 30 秒冷却池，避免无效心跳空转。
