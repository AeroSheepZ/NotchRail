# 0006. 常驻稳固视口与硬件级事件物理穿透

### 背景
浮动灵动岛面板在“紧凑胶囊态（32pt）”与“展开菜单态（84pt）”之间切换时，如果频繁调用 `panel.setFrame(...)` 更改物理窗口尺寸，macOS WindowServer 将反复重置并分配 GPU Surface 内存，导致边缘锯齿撕裂、阴影频闪及窗口跳动。此外，若窗口常驻且全尺寸拦截鼠标，其大面积透明区域将导致底层应用（如 Chrome 顶部标签栏、VS Code 菜单栏）无法被用户点击。

### 决议
1. **常驻稳固视口（StableViewport）**：`IslandPanel` 物理 Frame 始终锁定为全展开高度（84pt），展开与收起完全由 SwiftUI 内部的流体动画和矢量剪裁驱动，杜绝 OS 级窗口尺寸突变。
2. **硬件级物理穿透（HardwarePassthrough）**：通过 `MouseMonitor` 高频计算光标是否落在灵动岛当前有效黑色像素区域（紧凑刘海或展开胶囊），动态切换 `panel.ignoresMouseEvents`。未命中时 100% 物理直通底层应用，底层点击无任何阻滞。

### 理由与权衡
此方案保证了灵动岛展开/收起达到丝滑的 60/120fps 渲染性能，同时彻底消除了悬浮面板对系统原生应用的遮挡与误触隐患。
