# 0007. 全屏空间沉浸隐退与顶边缘热区唤醒

### 背景
macOS 在原生全屏应用空间（Full-Screen Spaces）下会自动隐藏系统菜单栏。若悬浮灵动岛在此状态下继续保持常驻，将严重遮挡全屏播放视频、全屏文档编辑或全屏演示的主界面内容；但若彻底关闭，用户在全屏下将无法访问被遮挡的扩展状态项。

### 决议
1. **全屏沉浸隐退（FullScreenStealth）**：通过 `FullScreenDetector` 结合前台 App 窗口的 `AXFullScreen` 属性及屏幕相交性，判定当前处于全屏空间时，自动将 `IslandPanel` 置为隐退状态（`alpha = 0`，`ignoresMouseEvents = true`）。
2. **顶边缘热区唤醒（TopEdgeHotZone）**：在屏幕最顶边缘建立 $\le 2\text{pt}$ 的沉浸交互热区。当光标碰触顶边缘时，跟随系统原生菜单栏平滑淡入唤出；移出交互区后保留 300ms 缓冲后平滑淡退。

### 理由与权衡
此机制完美融入 macOS 原生全屏心智体系：不主动打扰用户沉浸体验，仅在产生明确菜单查看意图时无感唤起。
